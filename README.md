# Поезија

Ова е едноставна SvelteKit апликација која прикажува „случајна“ песна секој ден.

Визијата е да се споделуваат македонски песни во едноставен формат со цел да се поттикне читањето (и некому да се разубави моментот).

## Додавање песни

Можете да додадете нови песни. Направете копија на еден од .md фајловите во `./src/lib/poems`, соодветно инкрементирајте го индексот во името на фајлот (на пр. `pesna.8.md`). Апликацијата автоматски ги препознава новите песни и ги вклучува во ротацијата. Следете го истиот формат како останатите песни и отворете pull request. Не заборавајте да ги додадете изворите, линкови како и лиценца ако треба. Потоа, ажурирајте ја листата подолу со достапни песни следејќи го азбучниот редослед. Фала!
